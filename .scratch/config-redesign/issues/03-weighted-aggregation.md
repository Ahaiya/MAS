# 03 — 观测点权重生效

**What to build:** 教研人员在量规里为各观测点写的 `weight`，真的影响 dim 的汇总分。

现状是配置说一件事、代码做另一件事：7 份量规每份都精心设定了权重（F2 是 0.4/0.6，
D3 是 0.25/0.25/0.3/0.2），而聚合写死等权平均，把量规作者对观测点相对重要性的判断
默默抹平了。

**这是唯一会改变历史分数的一票。** 量级说明，避免高估：F2 两个观测点得 3 和 4 分时，
等权 3.5、加权 3.6，差 0.1。在 1–4 量表、2–4 个观测点的规模下，加权与等权的差距通常
小于 0.2 分。且权重只影响 **dim（二级指标，如 `a1`）的汇总分**这一个派生数字——观测点
分数、证据引用、反馈文本一个字都不变。

改动落地后，历史产物与新产物的 dim 汇总分不可直接比较。

**Blocked by:** 02（校验保证 `weight` 必填且和为 1.0）

**Status:** ready-for-agent
