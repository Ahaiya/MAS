# 复杂工程问题解决能力评价指标

注：指标体系针对“AI赋能”进行了优化，带*的二级指标包含有AI相关能力要求。具体解释中涉及AI的内容用下划线标识。若复杂工程问题解决活动不涉及AI，则使用时可忽略带下划线的部分。

| **一级指标**                 | **二级指标**                     | **具体解释**                                                 |
| :--------------------------- | -------------------------------- | ------------------------------------------------------------ |
| **A** **问题认知与分析能力** | A1 复杂问题的识别和界定*         | 能够应用数学、科学及工程原理，通过工程观察、初步测试、文献研究等多种途径，识别并分析复杂工程问题的关键要素、变量和相互关系。从多维视角（如技术、社会、环境等）界定问题的研究范围、约束条件与核心需求。<u>关注适合利用AI进行的数据密集、模式识别、多变量优化等环节</u>。 |
| **A** **问题认知与分析能力** | A2 系统性思维与逻辑推理          | 将问题视为一个整体系统，分析其内部各组成部分的结构、功能及其相互作用，理解系统的整体行为。基于已有的科学原理、事实和数据，通过系统、严谨的逻辑推理，推导出合理的结论或假设。 |
| **A** **问题认知与分析能力** | A3 批判性思维与自我反思*         | 在问题解决全过程中**，**持续地对信息来源、分析方法及初步结论进行批判性评估。同时，对自身的思考和问题解决过程进行监控、评估和调整。<u>能认识到AI生成内容的潜在偏差与局限性（如训练数据时效性），明确其作为辅助（原料）与个人创造（产出）之间的区别，保持自身专业判断的独立性。</u> |
| **A** **问题认知与分析能力** | A4 用户需求与痛点分析*           | 能够深入分析工程问题所涉及的最终用户、利益相关者及其使用情境，识别显性与隐性需求，精准定位其面临的核心痛点与关键挑战。<u>关注AI辅助编制的解决方案如何与人的工作流程、决策习惯和组织文化相契合。</u>并基于核心需求定义与特定场景相适配的成功评价标准。 |
| **A** **问题认知与分析能力** | A5动态问题的适应性*              | 应对技术迭代/市场变化时，能够<u>（借助AI或数字化工具进行环境扫描与分析）</u>快速重构问题边界并调整分析框架。 |
| **B** **方案设计与创新能力** | B1 技术架构和功能模型*           | 为解决特定工程问题，构建出能够清晰表达解决方案结构、功能和工作原理的概念模型或数学模型。在方案中有效地融合与应用来自不同学科的知识与技术。<u>能够有效利用AI辅助设计工具（如生成式设计、拓扑优化AI）进行模型构建与探索。</u> |
| **B** **方案设计与创新能力** | B2 原型构建和可行性分析*         | 开发和实现解决方案的原型或实体模型；并设计、执行有效的测试方案以验证其关键功能与性能。<u>能够利用AI驱动的仿真（如基于机器学习的代理模型）高效地快速迭代和验证原型关键功能。</u>分析并判断方案在技术、资源、经济和操作层面是否可行。 |
| **B** **方案设计与创新能力** | B3 解决方案生成与择优*           | 针对核心问题，打破常规思维限制，提出新颖、巧妙、具有应用价值的解决路径。<u>能够利用AI工具激发创意、探索非传统方案，并高效生成、模拟和量化比较大量备选方案</u>。能够基于深刻的工程理解和多维度评价标准，从众多备选方案中筛选和优化出最具潜力的解决方案。 |
| **C** **项目实施与决策能力** | C1 进度计划和资源分配方案编制    | 为项目设定明确的时间表、关键节点和里程碑，确保任务能够按时有序推进。将复杂的项目目标分解为具体、可执行的任务单元，并合理安排团队成员的分工与协作流程。在项目实施过程中，对人财物等资源进行合理规划、分配与动态调整，以实现最高效率。 |
| **C** **项目实施与决策能力** | C2 潜在风险识别与应对策略*       | 在项目实施前和过程中，系统地识别可能对项目产生负面影响的不确定性因素，并针对已识别的潜在风险<u>（包括AI相关风险）</u>，制定预防性或应急性的计划和措施。<u>关注与AI模型失效、数据质量问题、算法偏见、安全风险、技术依赖等相关的风险。</u> |
| **C** **项目实施与决策能力** | C3 多源信息整合与审慎决策*       | 能够将数据分析与专业经验、逻辑推理相结合，作出工程判断和决策，并清晰阐述其决策逻辑。<u>能够批判性地利用AI模型（如预测模型、诊断模型、优化模型）辅助决策，并理解其不确定性。</u> |
| **C** **项目实施与决策能力** | C4 决策分析优化*                 | 运用系统化方法与模型建构决策过程，确保其逻辑性、全面性与科学性。在动态和不确定的环境中，能够灵活调整决策。<u>能够设计并应用人机协同决策框架，利用AI高效处理复杂信息，开展模拟仿真，并清晰界定AI的用途（如能力放大器、探索性工具），并明确人机双方在决策中的角色与权责。</u> |
| **D** **技术使用与掌控能力** | D1 工具的评估、选择、运用和优化* | 能够根据复杂工程问题的需求，评估、选择并有效应用合适的技术平台<u>（含AI工具）</u>及工具库<u>（如机器学习框架、数据分析平台、AI辅助设计/仿真工具）</u>；<u>应用适当的AI模型辅助解决问题，并理解其原理和局限性</u>；能够优化工具应用过程乃至进行二次开发。 |
| **D** **技术使用与掌控能力** | D2 标准规范应用与合规性检验      | 能够主动获取并理解相关技术标准、设计规范与法律法规。在技术应用和方案设计中，能够遵循标准，进行合规性检验。 |
| **D** **技术使用与掌控能力** | D3 获取、分析与解释数据*         | 能够设计并执行适当的实验方案，以科学、规范的方式收集研究所需的数据。<u>为训练/验证AI模型设计数据采集方案（考虑数据规模、质量、多样性、标注需求）</u>。规范数据采集过程。对数据进行整理、分析和解释，并利用工程判断从中得出合理、有效的结论。<u>能够分析、解释AI模型输出结果的含义、不确定性及其对工程决策的支持作用。</u> |
| **E** **沟通与团队协同能力** | E1 团队协作与跨文化交流*         | 在团队中，能够清晰定位自身角色（如负责人、成员），明确工作接口，并承担相应职责。能与其他成员在<u>AI辅助下</u>有效合作、整合资源，以达成共同目标；在全球化或多元文化背景下，借助<u>AI工具</u>理解并尊重不同的语言、文化习惯和工作方式。 |
| **E** **沟通与团队协同能力** | E2 高效沟通和表达能力*           | 能够通过书面报告、设计文档、口头陈述等方式，与业界同行及社会公众清晰、有效地交流思想和信息。<u>能够清晰解释AI模型的工作原理、结果及其局限，使非技术背景的利益相关者理解。</u> |
| **F** **职业发展与责任意识** | F1 职业规划与终身学习*           | 能够为自身职业生涯设定清晰、可行的发展目标，并基于此规划、选择和执行有效的学习策略，以持续获取和应用新知识（包含 <u>AI 新技术</u>、伦理规范、应用场景等），并能对学习成效进行反思与调整。 |
| **F** **职业发展与责任意识** | F2 工程伦理与社会责任*           | 在工程实践中，能够理解并遵守国家、行业及全球性的工程职业道德、规范和相关法律。<u>遵守AI伦理原则（如公平性、透明、问责等）</u>。能够识别并运用伦理框架分析工程实践中的伦理困境<u>（包括AI应用中算法偏见、隐私侵犯、自动化决策责任归属等）</u>，做出负责任的决策。 |
| **F** **职业发展与责任意识** | F3全局意识和可持续发展观*        | 具有大局观和全局意识，并勇于承担责任。能够综合考虑并致力于实现对环境、社会和经济协同发展的积极贡献。<u>利用AI技术促进资源效率、环境保护、社会公平等可持续发展目标的实现。</u> |
